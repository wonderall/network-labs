# Cisco CUCM 서버 지점 연동 작업

## 1. 작업 개요

### 작업 목적
신규 Cisco CUCM 서버를 VMware 가상화 환경에서 운영하고, 실제 물리적인 Windows 서버 2대를 데이터베이스 서버로 활용하여 약 1~2개월간 테스트 및 학습 환경을 구축한다.

대전에서는 내부 네트워크를 통해 CUCM 서버에 직접 접근할 수 있었으나, 서울 및 기타 지점에서는 접근이 불가능한 문제가 발생하였다.

이에 기존에 구축되어 있는 지점 간 GRE 터널링을 활용하여 각 지점에서도 Cisco CUCM 서버에 접근할 수 있도록 네트워크 연결 작업을 진행하였다.

### 작업 대상 지점
- 서울 4층
- 서울 12층
- 대전
- 진해
- 대전 이마트 매장
- 용인

## 2. 기존 네트워크 구성

### 서버 구성
- **Cisco CUCM 서버:** VMware 가상화 서버에서 운영
- **데이터베이스 서버:** 물리적인 Windows 서버 2대
- **서버 네트워크:** `7.x.x.x/24`
- **지점 간 연결:** Cisco 라우터 기반 GRE 터널링

### 기존 문제점
- 대전에서는 내부 네트워크를 통해 CUCM 서버에 직접 접근 가능
- 다른 지점에서는 CUCM 서버 네트워크로 접근 불가
- 기존 GRE 터널링은 구축되어 있었으나, CUCM 서버가 위치한 `7.x.x.x/24` 대역에 대한 지점 간 라우팅이 구성되어 있지 않거나 정상적으로 동작하지 않는 상태

## 3. 작업 진행 내용

### 3.1. 서버 연결 VLAN 구성

Cisco CUCM 서버 및 데이터베이스 서버가 사용하는 `7.x.x.x/24` 네트워크를 사내 네트워크에 연결하기 위해 Cisco 스위치에 VLAN 7을 생성하였다.

작업 내용:
- VLAN 7 생성
- CUCM 및 데이터베이스 서버 네트워크 연결
- 서버 네트워크와 스위치 VLAN 간 연결 상태 확인

### 3.2. 지점 간 GRE 터널 라우팅 구성

각 지점의 Cisco 라우터에서 GRE 터널링에 사용되는 IP 주소 및 기존 터널 연결 상태를 확인하였다.

이후 각 지점에서 CUCM 서버 네트워크인 `7.x.x.x/24` 대역으로 통신할 수 있도록 라우팅을 설정하였다.

작업 내용:
- 각 지점 Cisco 라우터의 GRE 터널 인터페이스 및 IP 주소 확인
- 기존 GRE 터널 연결 상태 확인
- `7.x.x.x/24` 네트워크에 대한 라우팅 설정
- 지점 간 서버 네트워크 접근 경로 확인

## 4. 작업 결과

- 모든 대상 지점에서 Cisco CUCM 서버 접근 가능 확인
- 대전 외 지점에서도 GRE 터널을 통한 CUCM 서버 통신 가능
- CUCM 서버에 화상회의 장치 연결 완료
- 지점 간 CUCM 서버 접근을 위한 네트워크 연결 구성 완료

## 5. 최종 결과 및 기대 효과

기존 GRE 터널링 인프라를 활용하여 별도의 신규 WAN 회선을 구축하지 않고도 각 지점에서 Cisco CUCM 서버에 접근할 수 있도록 구성하였다.

이를 통해 서울, 대전, 진해, 용인 등 각 지점에서 CUCM 및 화상회의 장치의 테스트와 학습을 진행할 수 있는 환경을 마련하였다.

본 구성은 약 1~2개월간 테스트 및 학습 목적으로 운영할 예정이다.

## 6. 기술 요약

| 구분 | 적용 기술 및 내용 |
|---|---|
| 가상화 | VMware |
| 통합 커뮤니케이션 | Cisco CUCM |
| 데이터베이스 | 물리 Windows 서버 2대 |
| 스위칭 | VLAN 7 |
| 지점 간 연결 | GRE 터널링 |
| 라우팅 | 서버 네트워크 `7.x.x.x/24` 경로 설정 |
| 작업 목적 | 지점 간 CUCM 접근 및 화상회의 장치 테스트 |

## 7. 추가 확인 사항

- 각 지점에서 CUCM 서버까지의 양방향 라우팅 확인
- GRE 터널 MTU 및 단편화 여부 확인
- CUCM 및 데이터베이스 서버 방화벽 정책 확인
- 테스트 종료 후 VLAN 및 라우팅 설정의 유지 또는 제거 여부 검토
